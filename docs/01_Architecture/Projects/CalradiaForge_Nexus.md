# CalradiaForge.Nexus

`CalradiaForge.Nexus` is a reserved optional assembly that references Core.
The current source inventory contains its project boundary but no implemented
Nexus feature surface that supports claims about authentication, REST calls,
downloads, NXM handling, credentials, or polling.

Future Nexus work must keep networking, credentials, downloader mechanics, and
transport in this project and remain optional to the base launcher.
