# CalradiaForge.Tests

`CalradiaForge.Tests` is the xUnit test project. It references Core and UI and
contains focused Core and UI contract tests for configuration, platforms,
launching, localization, logging, persistence, mod operations, results,
composition, lifecycle, dispatching, toasts, ViewModels, and the main window.

Test strategy and the exact commands belong in
[Development / Testing](../../06_Development/Engineering/Testing/README.md).
