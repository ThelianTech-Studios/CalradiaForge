# CalradiaForge.ConsoleUtils

`CalradiaForge.ConsoleUtils` is a developer-only .NET 10 console utility. Its
current menu generates the default English language file through Core's
translation services and moves the generated file into the repository's
`source/Languages` directory with overwrite support.

The utility is not part of the WPF runtime path. Its workflow is described in
[Engineering / Documentation](../../06_Development/Engineering/Documentation/README.md).
