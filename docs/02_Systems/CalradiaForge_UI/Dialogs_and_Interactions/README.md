# UI Dialogs and Interactions

Dialog services own WPF presentation for the EULA, language selection,
confirmation, and application lifecycle prompts. Interaction adapters isolate
file/folder pickers, shell launching, DLL unblocking, and the WPF dispatcher
from ViewModels. Core receives data and contracts rather than WPF types.

Detailed presentation rules belong in [Dialogs](../../../05_UI/Dialogs/README.md)
and [Interaction and State](../../../05_UI/Interaction_and_State/README.md).
