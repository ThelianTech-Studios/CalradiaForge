# Documentation Governance Policy

The active documentation model has one owner per concept, numbered canonical
domains, unnumbered lifecycle domains, direct cross-links, centralized
registration, explicit status labels, and source/test precedence. Canonical
docs describe current behavior; plans, reviews, archives, and templates do not
silently supersede them.

When a claim cannot be verified, classify the uncertainty and stop that
subsection. Reconcile the document map, registers, links, path lengths, and
supersession before closeout. Do not modify the preserved historical snapshot or
the separate agent-instruction system as part of ordinary docs maintenance.

See [DOCUMENT_AUTHORITY.md](../../DOCUMENT_AUTHORITY.md) and [Documentation
Maintenance](../../06_Development/Engineering/Documentation/README.md).
