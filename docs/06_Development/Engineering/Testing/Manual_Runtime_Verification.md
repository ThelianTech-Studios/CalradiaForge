# Manual Runtime Verification

Automated builds/tests do not establish the following manual evidence. An owner
or developer with the appropriate environment must record each scenario as
Directly Observed, Corroborated, Inconclusive, Blocked, or Fail.

Checklist:

- start with missing, valid, malformed, and inaccessible configuration;
- accept, decline, and close the EULA on first run;
- detect Steam across split libraries and the missing-Workshop case;
- manually select game and Workshop paths;
- install one archive, multiple archives, cancellation, failure, and retry;
- navigate away and return during active installation;
- inspect progress-to-terminal notification transitions;
- create, save, import, switch, and restore modpacks;
- launch Bannerlord and BLSE on a valid supported installation;
- verify Steam-not-running, unknown, start-failure, and timeout outcomes;
- change language and inspect retained page/ViewModel refresh;
- close while idle and while work is active; restart and delayed shutdown;
- inspect fresh startup, archived logs, and packaged/runtime output.

No scenario is marked observed by this documentation task alone.
