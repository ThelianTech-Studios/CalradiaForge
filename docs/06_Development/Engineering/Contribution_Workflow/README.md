# Contribution Workflow

Contributors should read the root [README](../../../../README.md),
[Architecture](../../../01_Architecture/README.md), and this workflow before
changing source.

1. Confirm the source-of-truth and scope.
2. Keep changes within the owning project and preserve dependency direction.
3. Add or update focused tests for changed contracts.
4. Run the relevant build/test commands and document limitations.
5. Complete review/fix passes and manual evidence where required.
6. Obtain owner review before release bookkeeping or Git publication.

Source-level history is recorded in [MIGRATION_MAP.md](MIGRATION_MAP.md).
Documentation-only changes do not create a source migration row under the
current policy.
