# Contributing

Keep contributions narrow, source-grounded, and compatible with the layered
architecture. Do not move WPF into Core, move Nexus networking into Core, store
credentials in configuration, bypass the authoritative mod installer/extractor,
or add startup/timed Nexus polling.

Before opening a change, read [Documentation Authority](../../../DOCUMENT_AUTHORITY.md),
[Engineering](../README.md), and the relevant canonical domain. Include the
verification commands and exact limitations in the review description. Release
and migration bookkeeping requires owner acceptance and an accepted source
endpoint.
