# Benchmark Methodology

Benchmark results must name the configuration, commit/source endpoint,
environment, corpus or fixture fingerprint, categories, warm/cold assumptions,
artifacts, and limitations. Real-installation measurements require explicit
consent and must not load application state, invoke the WPF app, start
Bannerlord, access Nexus, or use the network.

Measurements are owner-installation-specific. Do not infer UI responsiveness,
universal baselines, or component overhead by subtracting independently sampled
results. Findings remain pending until the owner/developer disposition is
recorded; this documentation task does not authorize production optimization.
