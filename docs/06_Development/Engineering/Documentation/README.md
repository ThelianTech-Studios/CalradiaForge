# Documentation Maintenance

Canonical docs, decisions, evidence, plans, archives, and templates have
separate roles. Read [Documentation Authority](../../../DOCUMENT_AUTHORITY.md)
before editing. Update one authoritative owner and its register together; use
cross-links instead of repeated specifications.

The structural map is generated deterministically from the actual tree during a
documentation change. A later manual audit should refresh it after tree/index
changes and check links, registrations, path length, supersession, and stale
claims. No generator or CI validator is implemented by this task.
