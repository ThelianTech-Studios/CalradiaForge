# Reviews

Reviews are evidence records, not canonical implementation specifications.
Each report has one primary classification and names its scope, baseline,
commands, evidence, limitations, and disposition.

| Type | Directory | Use |
| --- | --- | --- |
| Audits | [Audits](Audits/) | Documentation, source-state, release-readiness, and other audit reports |
| Implementation | [Implementation](Implementation/) | Accepted implementation summaries and closeout evidence |
| Verification | [Verification](Verification/) | Build, test, runtime, and release-verification records |
| Benchmarks | [Benchmarks](Benchmarks/) | Benchmark methodology and results |
| Diagnostics | [Diagnostics](Diagnostics/) | Narrow diagnostic and failure-analysis records |

Planning prompts and work orders belong under [Plans](../Plans/README.md) or
the archive, not here.
