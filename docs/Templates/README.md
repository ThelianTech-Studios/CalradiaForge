# Templates

Templates are reusable profiles, not finished documents. Remove instruction
comments and unused optional sections when applying one.

| Template | Profiles |
| --- | --- |
| [Canonical_Document.md](Canonical_Document.md) | Domain index, technical topic, capability, workflow, UI, data, engineering |
| [Decision_Record.md](Decision_Record.md) | ADR and policy |
| [Evidence_Report.md](Evidence_Report.md) | Audit, implementation, verification, benchmark, diagnostic |
| [Plan.md](Plan.md) | Active, queued, and work-order |
| [Closeout.md](Closeout.md) | Completed, abandoned, superseded |
| [Public_Release_Record.md](Public_Release_Record.md) | Confirmed public release only |
| [Cycle_History_Summary.md](Cycle_History_Summary.md) | Master-plan, locked-decision, and technical-closeout summaries |
