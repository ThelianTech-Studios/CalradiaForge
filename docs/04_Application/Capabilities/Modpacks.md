# Modpacks Capability

Users can create named modpacks, save the current order and active state, edit
and refresh them, import native JSON or supported Novus XML presets, and choose
startup selection behavior: last used, a default, or always ask. A built-in
Vanilla modpack is created when needed.

Modpack files are durable data; the service mechanism is documented in [Core
Modpacks](../../02_Systems/CalradiaForge_Core/Modpacks/README.md). The Launcher
and Modpacks ViewModels own presentation and commands.
