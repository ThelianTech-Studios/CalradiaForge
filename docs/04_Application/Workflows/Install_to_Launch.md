# Install to Launch

1. Confirm a valid game folder and modules directory in Settings.
2. Select a supported archive from the Launcher.
3. The Core pipeline validates/admit the install and reports correlated progress.
4. Installer/extractor mechanics run; required module DLL maintenance and
   bounded reconciliation follow where needed.
5. A terminal result and accepted snapshot determine the visible outcome.
6. Select or create a modpack, review active order, and choose Bannerlord or
   configured BLSE launch target.
7. The launcher validates platform readiness and starts only when allowed.

For exact outcome rules see [Mod Management](../Capabilities/Mod_Management.md)
and [Game Launching](../Capabilities/Game_Launching.md).
