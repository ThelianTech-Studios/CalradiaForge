# EULA Dialog

`EulaWindow` displays the text supplied by `EulaDialogService`. Core loads the
embedded EULA resource and persists acceptance; decline or closing the first-run
dialog prevents normal shell startup. See [Core EULA](../../02_Systems/CalradiaForge_Core/EULA/README.md)
for the state owner and the unresolved path-reservation discrepancy.
