# Packaging and Distribution

The product is documented as a portable Windows desktop application. The UI
targets Windows Desktop and the accepted source metadata is framework-dependent
with a Windows x64 publish direction in the existing repository materials.

Release packaging must verify the actual artifact, runtime availability,
included language/resources, license/notices, and output paths for the accepted
source endpoint. This document does not claim that a current packaged artifact
was rebuilt or published during the documentation overhaul.
