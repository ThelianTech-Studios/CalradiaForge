# Release Verification

Release verification combines, but does not conflate:

- solution build and test results;
- package/runtime and artifact inspection;
- manual WPF startup/navigation/close/restart scenarios;
- supported platform and Steam/Bannerlord launch scenarios;
- installer/modpack/recovery checks;
- version/changelog/artifact consistency;
- security and dependency-scan evidence.

The current documentation baseline records automated evidence and limitations
where retained reports provide it. Manual runtime and packaged-release checks
remain explicit gates when not observed. See [Manual Runtime Verification](../06_Development/Engineering/Testing/Manual_Runtime_Verification.md).
