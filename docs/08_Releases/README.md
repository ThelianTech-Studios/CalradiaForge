# Releases

This domain owns public-facing release process, version/artifact conventions,
release verification, distribution guidance, known limitations, and the
historical changelog. The changelog may contain internal builds; per-release
folders are limited to versions explicitly identified as public.

| Document | Role |
| --- | --- |
| [CHANGELOG.md](CHANGELOG.md) | Historical build and release record |
| [Release Process](Release_Process.md) | Owner-approved release sequence |
| [Versioning and Artifact Naming](Versioning_and_Artifact_Naming.md) | Version source and artifact identity |
| [Release Verification](Release_Verification.md) | Evidence gates and limitations |
| [Packaging and Distribution](Packaging_and_Distribution.md) | Portable distribution expectations |
| [Known Limitations Policy](Known_Limitations_Policy.md) | Release limitation classification |
| [Public-release records](Releases/) | Confirmed public releases only |

Confirmed public entries in the historical changelog are `0.12.15`, `0.11.5`
(public beta), and `0.9.22`. Internal, prerelease, phase, and development
entries do not receive release directories.
