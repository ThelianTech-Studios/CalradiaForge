## Documentation Conventions
- `Currently Implemented` describes behavior visible in source code today.
- `Planned / Locked Architecture` describes intentional design that is present in docs or code comments but not fully shipped.
- `Deferred / Future Work` describes work explicitly reserved for later.
- If a document overlaps another topic, prefer a short cross-reference instead of repeating the same details.
